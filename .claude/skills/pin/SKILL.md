# Пиннинг фото на Pinterest

Аккаунт: `vyukovoleg` (бизнес, домен vyukov.ru подтверждён). Публикуется ТОЛЬКО английский текст.

## Процесс (диалоговый цикл, по одному фото)

1. Пользователь даёт slug (и часто — авторское название/идею по-русски и город). Если slug не дан —
   предложи кандидата из очереди (см. «Очередь»).
2. Посмотри фото (`src/assets/photos/<slug>.jpg`) и YAML (`src/content/photos/<slug>.yaml`).
3. Составь тексты и покажи пользователю **на двух языках** (публикуется EN, RU — для контроля):
   - **Title** = авторское название + локация. Не дублировать название доски. Пример:
     `Strong and Independent — a Candid Street Scene in Kazan, Russia`.
   - **Description** = цепочки поисковых словосочетаний, БЕЗ беллетристики и пересказа видимого
     (пользователь считает это кринжем). Пример: `Candid street photography from Kazan, Russia.
     Summer embankment, everyday city life, people watching, urban scenes.`
   - Хэштеги НЕ использовать — в Pinterest они мертвы, работают слова в тексте.
   - Если город неизвестен — спроси: локация это сильный поисковый ключ.
4. Ссылка пина: `https://vyukov.ru/?utm_source=pinterest&utm_medium=pin#<slug>`.
5. После «ок» пользователя — публикация субагентом (см. ниже), затем запись состояния и коммит.
6. Авторское название дублируй в `title:` YAML (идёт на сайт и в будущем — в alt).

## Доски и раскладка по тегам

| Доска | Теги |
|---|---|
| Candid Street Photography | street (в т.ч. ночной) — дефолт для стрита |
| Street Portraits | street ∩ portrait |
| Black and White Street Photography | street ∩ b&w |
| Travel Photography — Cityscapes & Architecture | architecture |
| Travel Photography — Landscapes & Nature | landscape, animals |

Одно фото = одна доска (самая точная по сюжету). Досейв удачного пина на вторую доску —
только спустя недели, не при публикации.

## Очередь (управляет Claude)

Кандидаты: фото без блока `pin:`. Приоритет: `favorite: true` и `rating: 5`, свежие даты.
Ротация досок — не пропорционально каталогу: street-доски чаще (ядро каталога), travel вперемешку,
чтобы все доски наполнялись. Темп: 1–2 пина в день, массово не публиковать (антиспам Pinterest).

## Состояние в YAML (`src/content/photos/<slug>.yaml`)

```yaml
title: "Strong and Independent"   # авторское название → сайт
pin:
  title: "..."                    # EN title пина
  description: "..."              # EN description
  board: "Candid Street Photography"
  url: "https://ru.pinterest.com/pin/<id>/"
  pinned: 2026-07-26
```

Схема поля — в `src/content.config.ts`. После публикации: `npm run build` (санити) → коммит → push.

## Публикация: Sonnet-субагент + Chrome MCP

Публикует НЕ основной агент, а субагент (`model: sonnet`, general-purpose) — дешевле и не жрёт
контекст. В промпт субагенту дать: точные тексты, путь к jpg, доску, ссылку и рецепт ниже.
Браузер один — субагент только один, не параллелить.

Рецепт (проверено):
1. Инструменты грузить через ToolSearch: take_snapshot, click, fill, navigate_page, type_text,
   upload_file, wait_for (mcp__plugin_chrome-devtools-mcp_chrome-devtools__*).
2. Пользователь должен быть залогинен в Pinterest в браузере автоматизации (профиль постоянный).
   Если нет — остановиться и попросить залогиниться.
3. Пин-билдер: `https://ru.pinterest.com/pin-builder/`. Изображение — upload_file по uid
   файлового инпута.
4. **Грабли React-полей: `fill` не триггерит onChange** — значение видно в DOM, а на сервер уходит
   пустая строка. Вводить только кликом в поле + `type_text`. Это касается заголовка, описания,
   ссылки и описаний досок.
5. Грабли UI: первый клик по кнопкам с dropdown-меню часто съедается — нет меню в снапшоте, кликни
   ещё раз. Обучающие модалки Pinterest могут перехватить ввод — закрыть, поле очистить (Ctrl+A),
   ввести заново.
5a. **КАПЧА И БЛОКИРУЮЩИЕ ОВЕРЛЕИ — СТОП, а не обход.** Pinterest при частой публикации включает
   защиту: видимую recaptcha, невидимую reCAPTCHA (кнопка виснет на «Сохранение пина…», черновик
   теряется) или невидимый оверлей над кнопкой «Опубликовать». **Программно продавливать это
   нельзя** — ни JS-кликом мимо оверлея, ни любым другим обходом: это обход защитного механизма
   площадки и прямой путь к блокировке аккаунта. Правильно: остановиться, сообщить пользователю,
   дать ему решить. Появление капчи — сигнал, что темп превышен; на сегодня публикацию закончить.
   Проверено 2026-08-24 и 2026-08-25.
6. Выбрать доску, «Опубликовать».
7. Верификация обязательна: перезагрузка страницы доски (пин появился) + страница пина (сверить
   title/description/ссылку). При сомнениях — смотреть сетевые запросы (list_network_requests).
8. Субагент возвращает URL пина.

Снапшоты страниц большие: субагенту — сохранять в файл (`filePath`) и грепать, не читать целиком.

## Создание новой доски (редко)

Профиль `_saved` → «Создать пин или доску» → «Доска» → имя → на странице доски «Больше вариантов
для доски» (двойной клик) → «Редактировать информацию и настройки» → описание через type_text →
«Готово» → проверить перезагрузкой. Названия и описания досок — английские, с поисковыми ключами.
