# Публикация фото на Flickr

Аккаунт: `akagelo` (`flickr.com/photos/akagelo`), заведён в январе 2013, **бесплатный**.
Публикуется ТОЛЬКО английский текст.

## Ограничения бесплатного аккаунта (проверено 2026-08-16)

- **1000 фото** всего — потолок каталога на Flickr;
- не более **50 непубличных** файлов;
- только Safety Level **Safe**, коммерческая активность запрещена;
- **API-ключи бесплатным аккаунтам не выдают** («API key creation is currently disabled for free
  accounts»), поэтому всё делается браузером через Chrome MCP, как в скилле `/pin`. Скриптовый
  путь откроется только с Pro ($11/мес, $82/год) — решение отложено до оценки отдачи.

Настройки аккаунта уже выставлены: новые загрузки **публичные**, лицензия по умолчанию
**Public Domain Dedication (CC0)**, импорт геоданных из EXIF включён, из поиска ничего не скрыто.

## Чем Flickr отличается от Pinterest (важно для текстов)

| | Pinterest | Flickr |
|---|---|---|
| источник просмотров | поиск внутри сервиса | **группы**, теги, Explore |
| ссылка на сайт | поле пина | кликабельная ссылка в описании |
| текст | цепочки поисковых фраз | коротко; ключи живут в **тегах** |
| срок жизни | вечнозелёный | всплеск в первые сутки |

Отсюда: длинные SEO-описания на Flickr не нужны и раздражают сообщество. Ключевые слова
уходят в теги, описание — две-три строки плюс ссылка.

## Процесс (диалоговый цикл, по одному фото)

1. Пользователь даёт slug, либо предложи кандидата из очереди (см. «Очередь»).
2. Посмотри фото (`src/assets/photos/<slug>.jpg`) и YAML (`src/content/photos/<slug>.yaml`).
3. Составь и покажи пользователю **на двух языках** (публикуется EN, RU — для контроля):
   - **Title** — авторское название. То же, что в `title:` YAML (и в `pin.title` до тире), если
     фото уже пиналось: одно фото = одно название во всех каналах. Локацию в title не пихать —
     она уходит в теги и геометку.
   - **Description** — 2–3 строки: что за место/ситуация, без беллетристики (пользователь считает
     её кринжем), затем с новой строки ссылка `https://vyukov.ru/?utm_source=flickr&utm_medium=photo#<slug>`.
   - **Tags** — 10–20 штук, вот где ключи. Смешивать: жанр (`street photography`,
     `candid`, `documentary`), локация (`Moscow`, `Russia`, район), сюжет (`rain`, `alpaca`,
     `night`), техника (`black and white`, `telephoto`), плюс темы из `tags:` YAML.
     Многословные теги в нижнем регистре, как есть — про ввод см. «Грабли».
     **Не давать пары вида `street photography` + `streetphotography`** — Flickr считает их
     одним тегом и второй молча выбрасывает.
4. После «ок» — загрузка субагентом (см. ниже), затем запись состояния и коммит.
5. Авторское название дублируй в `title:` YAML, если оно там ещё пустое.

## Группы

Просмотры на Flickr приходят из групп, а не с профиля. Список групп аккаунта, их правила
и лимиты — в `groups.md` рядом с этим файлом (держать в актуальном состоянии).

### Постинг в группу — ТОЛЬКО по подтверждению пользователя, каждый раз

Никогда не добавлять фото в группу самостоятельно, даже если кадр очевидно подходит по теме
и даже если пользователь только что одобрил постинг этого же фото в другую группу. Одобрение
даётся на **конкретную пару фото ↔ группа**.

Перед каждым постингом показать пользователю, чтобы он мог решить сам:
- ссылку на фото — `file:///home/gelo/vyukov.ru/src/assets/photos/<slug>.jpg`;
- ссылку на **пул группы** — `https://www.flickr.com/groups/<slug>/pool/`, по нему видно
  уровень и характер того, что там лежит;
- название группы, её лимит постинга и требования из `groups.md`;
- своё соображение в одну строку, почему кадр туда ложится (или чем рискует).

Дальше ждать явного «да». Молчание, «ок» на другую тему или общее «погнали» — не согласие.

### Вступление в группу

Кнопка «Join» на странице группы. Две грабли:

- **JS-клик через `evaluate_script` не годится** — визуально кнопка меняется, а на сервер ничего
  не уходит. Только настоящий клик инструментом `click` по uid из снапшота.
- **У большинства групп после Join выскакивает модалка «Group Rules»** с кнопками «No, thanks» /
  «I agree». Без «I agree» вступления не происходит. **Правила читать перед согласием**, в том
  числе на неанглийском: встречаются условия, конфликтующие с жанром (`saojie` запрещает портреты
  людей без разрешения, то есть весь кэндид) или с форматом описаний (требование вставлять ссылку
  на группу в описание своих фото). Наткнулся на такое — нажать «No, thanks» и спросить
  пользователя, а не соглашаться молча.

Проверять результат не по кнопке, а по `https://www.flickr.com/people/akagelo/groups/`
(страница ленивая — проскроллить донизу).

### Прочее по группам

Раскидывать фото по 1–3 группам, самым точным по теме. Не веером во все — модераторы
вычищают такое как спам.

Следить за лимитом постинга (у части групп 1 фото в день, у части 5 в неделю) и за
требованиями обмена комментариями, если такая группа когда-нибудь появится в списке.
Нарушение — исключение из группы.

## Очередь

Кандидаты: фото без блока `flickr:`. Приоритет — `favorite: true`, `rating: 5`, и уже
пинившиеся кадры (у них есть проверенное название). Темп мягче, чем на Pinterest: Flickr
не наказывает за объём, но лента группы не любит заливки пачкой — 1–3 фото в день.

## Состояние в YAML (`src/content/photos/<slug>.yaml`)

```yaml
title: "Grey Season"              # авторское название → сайт
flickr:
  title: "Grey Season"
  description: "..."              # EN, с ссылкой на сайт
  tags: [street photography, moscow, russia, black and white]
  groups: ["Hardcore Street Photography"]
  url: "https://www.flickr.com/photos/akagelo/<id>/"
  posted: 2026-08-16
```

Схема — в `src/content.config.ts`. После публикации: `npm run build` (санити) → коммит.
Push копится пачкой (как у пинов).

## Загрузка: Sonnet-субагент + Chrome MCP

Публикует НЕ основной агент, а субагент (`model: sonnet`, general-purpose). Браузер один —
субагент только один, не параллелить (и не запускать одновременно с `/pin`).

В промпт субагенту дать: точные тексты, путь к jpg, теги, группы и рецепт ниже.

**Грузить пачкой, а не по одному.** Пять фото за один заход обходятся втрое дешевле пяти
отдельных циклов: одна навигация, один аплоад, одна кнопка публикации. Проверено на пяти
кадрах 2026-08-24.

Рецепт:
1. Инструменты грузить через ToolSearch: `take_snapshot`, `click`, `navigate_page`, `type_text`,
   `upload_file`, `wait_for`, `evaluate_script`, `press_key`
   (`mcp__plugin_chrome-devtools-mcp_chrome-devtools__*`).
2. Пользователь должен быть залогинен (профиль постоянный). Если нет — остановиться и попросить.
3. Загрузка: `https://www.flickr.com/upload` → `upload_file` по uid кнопки «Choose Files»
   (это стилизованный `<input type="file">`, работает штатно). **Для пачки — вызвать
   `upload_file` несколько раз подряд в тот же инпут**, файлы накапливаются в списке.
3a. В пачке у каждой карточки **свои инлайновые поля** Title и Description прямо в списке;
   фокус ставить через `evaluate_script`, текст — через `type_text`. Теги вводятся в правой
   панели «Add tags» для выделенной карточки — выделять карточку перед вводом её тегов.
   **Панель тегов сворачивается при каждом переключении карточки** — перед вводом тегов
   очередного фото кликать по заголовку «Add tags», иначе вводить некуда.
4. **После аплоада в DOM ДВА набора полей Title/Description**: пустой decoy и настоящий
   (в нём уже лежит имя файла в заголовке). Слепой клик по первому textbox из снапшота
   попадёт в decoy, и введённое пропадёт. Сначала через `evaluate_script` найти инпут
   с непустым `value` — работать только с ним.
5. Title и Description: клик в поле + `type_text` (`fill` не тригерит onChange), после ввода
   сверять посимвольно через `evaluate_script`. Пустая строка между абзацами описания —
   двойной `press_key Enter` между двумя `type_text`.
6. **Теги — главная грабля. Многословный тег вводить В ДВОЙНЫХ КАВЫЧКАХ**: `"street photography"`
   + Enter. Без кавычек Flickr разобьёт его по пробелам на отдельные теги (`street`,
   `photography`). Однословные — как есть; можно строкой: `"street photography" candid documentary`
   даёт ровно три тега. После ввода всех проверить список чипов
   (`#editr-panel-tags-content .tag-wrapper a`): количество и целостность.
7. Проверить, что privacy = Public и лицензия = CC0 — подтягиваются из дефолтов аккаунта.
8. Кнопка «Upload N Photo(s)» — одна на всю пачку → **модальный диалог подтверждения**
   «Upload N items with the following changes?» с кнопками «Upload» / «Continue Editing» →
   жать «Upload».
8a. **Диалог подтверждения может не попасть в accessibility-снапшот** (отрисован, но a11y-дерево
   его не видит). Не считать это отсутствием диалога: снять скриншот, затем взять свежий снапшот —
   со второго раза кнопки «Upload» / «Continue Editing» появляются.
9. **Рекламный интерстишл free-аккаунта** «Upgrade everything you do with Flickr» с кнопкой
   «Continue to Flickr». Кнопка часто не срабатывает — не воевать с ней, а идти сразу
   на `https://www.flickr.com/photos/akagelo/` и брать свежий пост из потока.
10. **Верификация обязательна**: открыть страницу КАЖДОГО залитого фото отдельно, сверить
    title/description/теги, убедиться, что фото публичное и лицензия CC0. Не верить списку
    в потоке — там теги не видны. Если снапшот страницы не показывает блок тегов, читать их
    напрямую: `evaluate_script` по `a[href*="/photos/tags/"]`.
11. Группы: субагент их **не трогает**. Постинг в группы идёт отдельным шагом и только после
    подтверждения пользователя по каждой паре фото ↔ группа (см. раздел «Группы»).
12. Вернуть URL фото вида `https://www.flickr.com/photos/akagelo/<id>/`.

Снапшоты страниц большие: субагенту — сохранять в файл (`filePath`) и грепать, не читать целиком.

## Грабли

- **Дефолт приватности.** Историческая причина мёртвого аккаунта: в настройках стояло
  «View: Only you», всё залитое было приватным. Исправлено 2026-08-16, но при странностях
  проверять `flickr.com/account/prefs/photoprivacy/`.
- **Многословный тег вводится только в двойных кавычках** — `"street photography"`. Без них
  Flickr режет по пробелам на отдельные теги. Проверено 2026-08-16.
- **Если Enter не превращает введённое в чипы** (поле держит сырой текст, счётчик остаётся 0/75,
  повторные Enter и Escape не помогают) — жать **Tab**, он коммитит теги надёжно. Поведение
  непостоянное: в одной пачке часть карточек берёт Enter, часть только Tab. Проверено 2026-08-25.
- **Пробел не создаёт новый тег.** `street photography` и `streetphotography` Flickr считает
  одним и вторую форму молча выбрасывает (из 16 введённых сохранилось 15). Обе формы давать
  бессмысленно — занимают попытку, но не место в поиске.
- **Удалить ошибочный тег кликом по чипу нельзя** — чип это `<a href="#">`, клик только дёргает
  хэш. Нужно навести на него инструментом `hover` (синтетический `mouseover` через
  `evaluate_script` не работает), дождаться карточки, снять новый снапшот и нажать «Remove».
- **`navigate_page` регулярно кидает `Navigation timeout exceeded`, хотя страница загрузилась.**
  Не считать это провалом: проверять `document.readyState` и `document.title` через
  `evaluate_script` и работать дальше.
- **Геометка** подтягивается из EXIF автоматически (включено). У части кадров EXIF без GPS —
  тогда геометки не будет, руками не ставим.
